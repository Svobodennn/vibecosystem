# Cross-Project Learning — Codex

Cross-project learning otomatik bir pipeline degildir.

## Kaydetme kapisi

1. Ogrenimin gercekten tekrar kullanilabilir oldugunu kanitla.
2. Projeye ozelse proje talimatina/notepad'ine kaydet.
3. Codex-native memories etkinse resmi memory yuzeyini kullan.
4. `~/.codex/memories_1.sqlite` bir implementation detail'dir; dogrudan sorgulama veya yazma yapma.
5. Baska projeye promote etmeden once en az iki bagimsiz proje kaniti ve kullanici onayi al.

Hook tarafinda trusted learner/consolidator/loader yoksa otomatik capture, promotion veya injection varmis gibi davranma. Manuel kayit ve acik kaynak gosterimi gecerlidir.
